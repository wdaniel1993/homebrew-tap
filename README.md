# Homebrew tap for Lunate

`brew tap wdaniel1993/tap && brew install lunate`

The formula in `Formula/lunate.rb` is filled from the release it points at: the macOS
Apple Silicon and Linux x86_64 archives published on
[the Lunate releases page](https://github.com/wdaniel1993/lunate/releases), with their
SHA-256 values. The canonical copy lives in the Lunate repository under `packaging/homebrew/`
and is refreshed on every release.

Nothing is published here before the first tagged release exists.
